## Overview

Narwhal Assistant is a lightweight productivity and discovery tool designed to make information retrieval and workflow exploration faster and more focused.

## Core idea

It helps users move from an initial goal to useful output without the usual friction of searching, sorting, and re-finding information across multiple sources.
