# Getting started with Narwhal Assistant

## Install

1. Visit the Gumroad download page:
   https://azureknight85.gumroad.com/l/narwhalAssistant
2. Complete the purchase or access flow.
3. Download the package.
4. Install it using the instructions provided with the download.

## First run

After installation, launch Narwhal Assistant and begin with a clear goal or question. The assistant is designed to help reduce friction in discovery and help you focus on what matters most.

## Typical use cases

- exploring new ideas quickly
- narrowing a search to relevant results
- organizing a workflow around a goal
- reducing time spent on repeated discovery tasks

## Tips

- Start with a specific question or objective.
- Keep tasks focused so the assistant can help narrow the path.
- Use it as a lightweight discovery layer rather than a heavy workflow system.
